# 去土味硬护栏（Anti-Slop Guardrails）

本规则库由实测踩坑总结，强制注入所有提示词编译与 HTML 渲染流程，用于彻底消灭 AI 封面的廉价模板味：

1. **严禁 Word 艺术字与硬黑投影**：标题文字一律采用干净扁平的高对比编辑排版，禁止给亮色大字加浓重黑描边、硬投影或塑料 3D 斜面（极易退化成老式汇报 PPT）。
2. **严禁通用 AI 刻板元素**：禁止蓝紫渐变背景、发光全息大脑、悬浮代码雨、电路板光晕、毛玻璃圆角弹窗、发光荧光箭头。
3. **明暗锁死，绝不混搭**：
   - 背景色相对亮度（WCAG Relative Luminance）`< 0.32` 判定为 **深底色卡（dark）**，只能匹配支持 `dark` 的版式（如暗黑现代主义、2D 像素闯关、深底杂志双栏、深底瑞士网格）；
   - 背景色亮度 `>= 0.32` 判定为 **浅底色卡（light）**，只能匹配支持 `light` 的版式（如复古手撕拼贴、复古时代错位杂志、东方极简留白、浅底双栏）。
4. **严格色号分工，不均分面积**：主底色占 60%–75%，标题与视觉主色占 15%–25%，点缀色严格控制在 5%–15% 以内。
5. **单一视觉隐喻原则**：整张封面只讲一个画面故事，不堆叠多个小图标、徽章、卖点列表或无关装饰；文字区保留足够呼吸留白，确保手机 270px 缩略图一眼能读清主标题。
6. **文字准确度优先**：如果当前生图模型中文渲染不稳定，或封面需要高频改标题、做系列统一视觉，优先走 **引擎 A（AI 无字主体 ＋ 代码精准 HEX 排版）** 或 **`swiss-typo-pure`（零生图纯大字版）**，从根源实现 100% 零错字与 100% 精确 HEX 还原。
